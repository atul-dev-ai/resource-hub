# Code of Conduct

## Our Commitment

We are committed to providing a respectful, professional, and harassment-free environment for everyone contributing to this project.

## Expected Behavior

* Be respectful and constructive
* Communicate clearly and professionally
* Accept feedback and criticism gracefully
* Focus on improving the project, not individuals

## Unacceptable Behavior

* Harassment, abuse, or offensive language
* Personal attacks or insults
* Spam or irrelevant contributions
* Plagiarism or misrepresentation of work
* Any attempt to disrupt the project or community

## Contribution Standards

* Follow all contribution guidelines
* Submit only relevant, tested, and meaningful changes
* Maintain code quality and structure
* Respect project decisions made by maintainers

## Enforcement

Maintainers have full authority to:

* Reject contributions
* Remove inappropriate content
* Restrict or ban contributors who violate rules

## Reporting Issues

If you experience or witness unacceptable behavior, report it to the maintainers.

## Final Note

This project is focused on quality and collaboration.
Failure to follow this code of conduct will result in strict action.
